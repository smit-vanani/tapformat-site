Questions

Before you download.

Is it really free?

Yes. Download it and convert as much as you like.

Why does macOS say it can't verify Tapformat?

Tapformat isn't registered in Apple's paid developer program yet, so macOS asks you to confirm it the first time. Click Done, then open System Settings → Privacy & Security and click Open Anyway. You only do this once, and updates install automatically after that.

Why does it ask for Accessibility permission?

macOS only lets an app notice a key tap made inside Finder if you allow it under Accessibility. Tapformat uses it to spot the ⇧⌘ tap and nothing else. It doesn't read or store what you type.

Why does it ask to control Finder?

That's how it finds out which files you've selected when you tap ⇧⌘. macOS shows a one-time prompt for it.

Which Macs does it run on?

Any Mac with Apple silicon or Intel running macOS 15 Sequoia or later.

Can I change the shortcut?

Yes. In Settings you can switch to ⌥⌘ or ⌃⌥.

Can it convert a whole folder of photos?

Select as many files as you like and tap ⇧⌘ once. The ring only offers formats every selected file supports, and several images can also become one PDF.

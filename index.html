Tapformat FAQ9 answers
Is it really free?

Yes. Download it and convert as much as you like.

Is it safe to install?

Yes. Tapformat is notarized by Apple, which means Apple scanned it for malware and checked who built it. It opens like any other app, with no security warning.

Why does it ask for Accessibility permission?

macOS only lets an app notice a key tap made inside Finder if you allow it under Accessibility. Tapformat uses it to spot the ⇧⌘ tap and nothing else. It doesn't read or store what you type.

Why does it ask about my Desktop and Documents folders?

Tapformat saves the converted file right next to the original, so macOS asks once per folder before it can write there. The welcome guide asks for all of them in one go. To never see a folder prompt, turn on Tapformat in System Settings → Privacy & Security → Full Disk Access (optional; Settings → Your Mac has a shortcut).

Why does it ask to control Finder?

That's how it finds out which files you've selected when you tap ⇧⌘. macOS shows a one-time prompt for it.

Does Tapformat track what I convert?

Your files never leave your Mac. The app sends an anonymous count of how many files it converted (like "3 images"), never the files, their names or anything about you. You can turn it off in Settings → Your Mac → Share anonymous usage count.

Which Macs does it run on?

Any Mac with Apple silicon or Intel running macOS 15 Sequoia or later.

Can I change the shortcut?

Yes, to anything you like. Pick ⌥⌘ or ⌃⌥ in Settings, or click Record your own and press any combination: a tap like ⌃⇧, or keys like ⌥Space or ⌃⌘K. It only listens while Finder is in front, so other apps keep their shortcuts.

Can it convert a whole folder of photos?

Select as many files as you like and tap ⇧⌘ once. The ring only offers formats every selected file supports, and several images can also become one PDF.
